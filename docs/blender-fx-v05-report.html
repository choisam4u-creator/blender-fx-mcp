v0.5 — 미뤄 뒀던 7개 전부 완료

2026-09-20 · 공개 전 마지막 기능 묶음. 도구 28개, 테스트 24개

결론

v0.4 문서에서 "아직 안 만든 것"으로 남겼던 7개를 모두 만들었습니다. 가장 위험했던 되돌리기는 실제 블렌더 창을 띄운 소켓 경로로 확인했고, 되돌린 뒤에도 블렌더와 연결이 끊기지 않았습니다.

1. 먼저, 약점

  1. 되돌리기는 파일을 다시 엽니다. 저장하지 않은 지금 장면은 사라집니다. 블렌더 자체의 "되돌리기(Revert)"와 같은 방식이라, 여러 단계 실행 취소(Undo)가 아닙니다.
  2. 조각 접착은 느립니다. 조각 60개에 제약 145개가 생깁니다. 조각을 200개 넘게 하면 굽기가 눈에 띄게 길어집니다.
  3. 하늘 텍스처는 빠른 미리보기에 안 보입니다. 워크벤치는 하늘을 단색으로 그립니다. 확인하려면 quality="smoke" 이상이 필요합니다.
  4. HDRI는 파일이 있어야 합니다. 인터넷에서 받아오지 않습니다. 없는 경로를 주면 한 줄로 알려 줍니다.
  5. 영어 메시지는 문장만입니다. 도구 설명(AI가 읽는 문서)은 아직 한국어입니다. AI는 둘 다 읽지만, 영어권 기여자에게는 불편합니다.
  6. 창문은 벽에 붙인 판입니다. 진짜 구멍이 아니라서 안이 비치지 않습니다. 부서질 때 같이 깨지긴 합니다.

3. 중간에 잡은 문제

  • 낙하 높이가 항상 0이었습니다. 마지막 프레임에서 재야 하는데 프레임을 1로 되돌린 뒤에 재고 있었습니다. 접착 비교 테스트가 이걸 잡아냈습니다.
  • 하늘이 두 번 비췄습니다. 하늘 텍스처와 태양이 같이 비춰 바닥이 하얗게 날아갔습니다. 하늘 조명이 켜지면 태양을 45%로 낮췄습니다.
  • 접착이 있으면 조각이 잠들면 안 됩니다. 기본은 맞기 전까지 조각을 재워 두는데, 접착은 힘을 전달해야 해서 접착이 있을 때만 깨워 둡니다.
