v0.6 완료 · 깃허브 공개

2026-09-20 · github.com/choisam4u-creator/blender-fx-mcp

결론

요청한 세 가지를 다 만들고 공개했습니다. ① 아무 메시나 부피를 보존하며 보로노이로 부서집니다. ② 물은 방향·기울기·속도·모양·점성을 지정할 수 있습니다. ③ 숨어 있던 설정을 전부 인자로 꺼냈습니다. 기존 약점 9개도 처리했습니다. 테스트 32개 통과, 깃허브에서 바로 설치해 실행되는 것까지 확인했습니다.

1. 먼저, 남은 약점

  1. 보로노이는 조각 수에 민감합니다. 140조각에 약 2초지만, 400조각이면 훨씬 오래 걸립니다. 각 조각마다 불리언을 한 번씩 돌리기 때문입니다.
  2. 접착(glue)은 여전히 느립니다. 140조각에 제약 352개가 생깁니다. 줄이는 인자는 열어 뒀지만 본질은 그대로입니다.
  3. 물은 격자 크기가 전부입니다. 물 덩어리가 계산 칸보다 작으면 사라집니다. 지금은 사라지는 대신 "resolution 을 얼마로 올리세요"라고 알려 줍니다.
  4. 되돌리기는 여전히 파일 단위입니다. 직전 상태를 자동 저장해 한 번은 되돌릴 수 있지만, 여러 단계 실행 취소는 아닙니다.
  5. 연기는 어떤 형식으로도 내보낼 수 없습니다. Alembic 으로 물 표면과 조각은 나가지만 볼륨 연기는 블렌더 안에만 있습니다.
  6. 실제 소켓 경로 재검증을 v0.6 에서는 하지 않았습니다. 통신 코드는 v0.5 이후 그대로이고, 모든 검증은 블렌더를 창 없이 띄운 실제 계산으로 했습니다.
  7. 도구 설명은 영어 한 줄 + 한국어 본문입니다. 완전한 영어화는 v1.0 으로 남겼습니다.

2. 요구 ① 아무 메시나, 물리에 맞게

바뀐 것확인한 근거
무작위 평면 → 보로노이 셀 + 정확 불리언조각 부피의 합이 원본과 일치. 단순 상자 1.000, 창문 건물 1.001, 140조각 1.001
열린/깨진 메시 자동 수리면 두 개를 지운 껍데기 상자를 shell_thickness 로 두껍게 해 20조각으로 부숨
inspect_mesh 진단닫힘 여부·부피·오목한 정도(볼록 비율 0.962)·면 수·수리 예상, 주의 문구 자동 생성
조각 분포 pattern·focusimpact/uniform/radial/slabs 4종. 맞은 곳 집중은 거부 표본으로 전체를 덮으면서 밀도만 높임
충돌 모양·재질·속 재질재질 8종, collision 5종, 단면에 다른 재질(렌더에서 확인)
모든 조각이 닫힘open_chunks 0. 단면을 고리 단위로 직접 이어 붙이는 방식으로 교체

중간에 잡은 문제: 셀이 이웃 12개만 보고 잘려 서로 겹쳤습니다(부피 958%). 씨앗에서 가장 먼 꼭짓점보다 먼 이웃은 자를 수 없다는 규칙으로 정확히 끝내도록 고쳤습니다. 또 창문이 별도 껍데기라 단면 메움이 엉켰는데, 창문을 벽에 실제로 파내 하나의 닫힌 껍데기로 만들어 해결했습니다.

3. 요구 ② 물을 마음대로

인자확인한 근거
mode 4종drop(떨어짐, z -2.01m) / stream(옆으로) / pool(바닥에 참) / object(내 메시가 물)
direction_deg, pitch_deg, speed90도로 쏜 물이 실제로 +X 로 2.13m 이동, 옆으로는 0.6m 미만으로만 샘
liquid 6종 + 점성·표면장력같은 조건에서 물과 꿀의 이동량·모양이 다름(꿀 1.76m, 물 2.13m). 실제 그림에서도 굵기와 색이 다름
gravity_scale, obstacles, spray중력 배율, 부딪힐 물건 지정, 물보라 계산 플래그
공간 자동 계산장애물 + 출발점 + 날아갈 거리를 담아 도메인을 잡음. 넓은 바닥판은 계산에서 제외

4. 요구 ③ 설정 개방

  • set_physics: 중력 세기·기울기, 하위 단계, 해석 반복, 물리 속도, fps. 중력 0에서 조각이 안 떨어지는 것으로 검증(낙하 0.1m 미만)
  • set_render: 샘플, 모션블러, 해상도, 노출, 필름 룩, 배경 빼기
  • destroy: density·friction·bounce·margin·collision·pattern·focus·interior·repair·shell_thickness·decimate_to·neighbors
  • fire/smoke: density·dissolve·vorticity·noise·burn_rate, 해상도 자동
  • particles: size·gravity·drag·lifetime·speed·randomness
  • 모두 프리셋 + 덮어쓰기 구조. 값을 안 주면 프리셋 그대로라 AI가 헷갈리지 않습니다.

5. 기존 약점 처리

약점해결
조각이 각짐보로노이로 교체 (완료)
창문이 판때기벽을 실제로 파내고 안쪽에 유리 (완료)
슬로모션이 파티클에 안 걸림set_timing(global_slow=) 로 장면 전체 시간 확장. 24프레임 → 48프레임 확인
물·연기를 내보낼 수 없음Alembic(.abc) 내보내기. 물 표면과 조각이 프레임마다 담김 (연기는 여전히 불가)
되돌리기가 1단계되돌리기 직전 상태를 before_restore 로 자동 저장
하늘이 빠른 미리보기에 안 보임도구가 "빠른 미리보기라 안 보인다"고 알려 줌
불이 해상도를 타야 함resolution=0 이면 대상 크기로 자동 결정
도구 설명이 한국어뿐모든 도구 설명 첫 줄에 영어 한 문장
충격체가 폭발처럼 튐손으로 옮기는 구간을 표면까지만. 안으로 파고들어 겹침이 터지던 문제 수정
