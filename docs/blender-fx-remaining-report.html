2026-09-21 · v0.6.3 · 로컬 파일만 사용, 내려받기 0건

결론

다섯 가지 다 끝냈습니다. 그리고 또 렌더가 버그를 잡아냈습니다. 팔을 벌린 캐릭터를 부수면 조각은 났는데 제자리에 그대로 서 있었습니다. 때리는 공이 팔 끝 바깥 허공을 치고 있었습니다. 숫자로는 "조각 39개 완성"이라 멀쩡해 보였습니다.

1. 이번에도 숫자는 조용했다

때리는 공을 상자(바운딩 박스) 면에 대고 조준하고 있었습니다. 팔을 벌린 T 포즈는 가로 1.83m인데 몸통 두께는 0.35m뿐입니다. 그래서 공이 팔 끝 바깥에서 멈추고 그대로 바닥으로 떨어졌습니다.

이제 광선을 쏴서 진짜 표면을 찾습니다. 요청한 높이에서 빗나가면 높이를 훑어 맞는 자리를 찾습니다. 덤으로 데모 건물도 더 잘 무너집니다.

2. 4번 — .blend 가져오기

됩니다. 다만 리깅 조작용 위젯이 132개 같이 딸려와 전부 합쳐지고 있었습니다. 뼈대를 움직이는 손잡이 모양들인데, 면이 하나도 없어서 부술 수 없는 것들입니다.

이제 면이 없는 부품은 자동으로 뺍니다. 결과적으로 character 하나만 남습니다. 1.83 × 0.35 × 2.0m, 조각 39/40, 부피 보존 1.006 입니다.

4. 6번 — 실제 경로 확인

블렌더 앱을 띄우고 수신기를 켠 뒤, 말로 시키는 실제 경로를 끝까지 돌렸습니다. v0.5 이후 처음입니다.

12단계 전부 성공했습니다. 진단 → 연결 확인 → 건물 만들기 → 바닥 → 카메라 → 스냅샷 → 파괴 → 목록 → 되돌리기 → 목록 → 스냅샷 목록. 그림도 제대로 돌아왔습니다.

블렌더는 지금도 켜 둔 채입니다. 수신기가 살아 있어서 클로드에서 바로 시켜 볼 수 있습니다. 필요 없으면 Cmd+Q 로 끄시면 됩니다.

5. 5번·8번

  • 눈으로 보기 — 이번 작업의 핵심이었습니다. 렌더 없이는 "조각 39개 완성"이라는 숫자만 보고 넘어갔을 겁니다.
  • 배포 파일 — 0.6.0 으로 낡아 있던 설치 파일을 새로 만들었습니다.

6. 남은 것

  • 조각 2~4개가 닫히지 않습니다. 그 조각의 무게는 어림값입니다.
  • 부품끼리 관통하는 모델은 느립니다. 50조각에 약 100초입니다.
  • 먼지가 큰 구슬처럼 보입니다. 크기를 줄이는 게 좋아 보입니다.
  • 조각 단면에 텍스처가 안 붙습니다. 겉면은 원래 재질, 단면은 단색입니다.
  • 뼈대 애니메이션은 따라가지 않습니다. 현재 자세로 굳혀서 부숩니다.
